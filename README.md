# Seguridad aérea

Blog académico del grupo IAM24-07A, preparado con apoyo de IA y pendiente de revisión final por el equipo.

## Publicación
En Settings → Pages, seleccionar Deploy from a branch, main y /(root). Los archivos del sitio están en la raíz.

## Pendientes
- Configurar comentarios públicos y moderación.
- Integrar tres herramientas digitales diferentes (las actividades locales de JavaScript no sustituyen ese requisito).
- Incorporar correo exclusivo del proyecto y revisar el aviso de privacidad.
- Revisar el contenido y autoría con el equipo.

No se requiere un dominio de pago para usar GitHub Pages.
